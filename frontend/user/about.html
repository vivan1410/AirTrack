AirTrack Platform

A smart airport information and operations platform for flight tracking, gate management and operational alerts.

What is AirTrack?

AirTrack is a simulated airport flight and gate management platform designed to provide passengers and airport operations teams with a unified view of flight schedules, gate assignments, delays and operational alerts.

What AirTrack Provides

1. Flight Status Monitoring Track scheduled and estimated flight information in real-time.
2. Gate Management Monitor terminal gates and current docking aircraft assignments.
3. Smart Gate Changes Automatically propagate gate reassignment events to indicators.
4. Airport Announcements Display important operational updates to terminals dynamic banners.
5. Passenger Watchlist Allow passengers to monitor selected flights and receive quick updates.
6. Disruption Center Surface flight delays, cancellations and gate changes on a single hub.
7. Smart Concourse Finder Help passengers identify their terminal gates concourses location.
8. Operations Simulator Demonstrate airport operational dispatch changes via dispatcher inputs.

How AirTrack Works

Architectural pipeline routing operations data from user client down to data tier.

1. Client Level
Passenger / Airport Operator Client View

Renders dashboards, search autocompletes, watchlist trackers, and simulator trigger decks.

2. Application Code
AirTrack Web App (HTML + CSS + ES6 JS)

Manages local rendering engine, pathname routing mappings, and localStorage synchronization drivers.

3. Service Endpoint Gateways
REST API Layer (Express router endpoints)

REST API routes (/api/flights and /api/gates) prepare response arrays ready for backend connections.

4. Server Middleware
Node.js + Express Server Layer

Serves static files, hosts page routes under clean URLs on port 8080, and forwards database updates.

5. Data Storage Matrix
PostgreSQL Database (Supabase Cloud Config Client)

Intended cloud database storage tier schema templates.

CURRENT DEMO Local simulated data engines syncing to browser localStorage fallback.
TARGET CLOUD ARCHITECTURE Full REST API integrations syncing database updates directly to cloud PostgreSQL models.

Smart Event Workflow

How state changes propagate through AirTrack components during a gate reassignment event.

1
GATE CHANGE TRIGGER Flight AI 539 reallocated: Gate B04 → Gate A05
2
Flight operational state record updated
3
Previous allocation Gate B04 released (Available)
4
New allocation Gate A05 assigned (Occupied)
5
Operational gate reassignment announcement generated
6
Unread alert flag pushed to watchlisted passengers
7
FIDS Flight Status Board updates to gate A05
8
Gate Status Monitor shifts card B04 → empty, A05 → occupied
9
Operational summaries and charts re-calculated dynamically
